# BMeshGeneration

This is a little showcase of generating a 3D model from multiple nodes.

We Create Nodes that represent the body part of the model and hierarchise them with the unity hierarchy transform.

# Functionalities

- Mesh Generation from nodes (similar to skin modifier in blender)
- Mesh subdivision

### v2026 - news

- Unity 6.0 native support
- Mesh smoothness
- Mesh armature generation
- Mesh export (obj, json, dae)
